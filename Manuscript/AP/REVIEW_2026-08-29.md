## Side result relevant to the p < 1/2 programme (not for this paper)

High-precision computation (320 digits, n ≤ 1300) shows that for
p = 0.45 and p = 0.42 the optimal value `w_{n,p}` *converges* (relative
oscillation ~1e-39 over n ∈ [150, 320]) while the greedy value `b_{n,p}`
oscillates log-periodically (amplitude ~1e-6 at p = 0.45). The optimal
policy has a "magic number" structure (suffix-maximum records of w):
p = 0.45: {1,2,3,4,15,167,…}; p = 0.42: {1,…,6,9,10,43,273,…}. With j
tails one keeps the smallest magic number ≥ j, and plays ONE if none lies
in [j, n−1]. `w_n < w_{n−1}` occurs only at the birth of a new magic
number (n = 168 for p = 0.45, difference −8e-46; n = 274 for p = 0.42,
difference −6e-67), confirmed identical at 100 and 200 digits. This
contradicts the non-convergence route (Gap D(ii)) of
`Oscillation/paper3.tex`.
